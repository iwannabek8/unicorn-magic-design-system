The idea

Tunable joy.

One knob, whole system

--ag-vibe scales sparkle opacity, gradient saturation, border radius, and animation amplitude. Same components, radically different register.

Semantic tokens

Components read --ag-color-accent, not --ag-pink-hot. Rebrand in a coffee break.

Sparkles as reward

Motion is tied to state changes — success, acknowledge, transition — not ambient decoration. Reduced motion collapses cleanly.
